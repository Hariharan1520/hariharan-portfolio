# Premium Dark AI Engineering Portfolio

A modern, high-performance, responsive portfolio website designed specifically for AI Systems Engineers, Data Scientists, and Machine Learning Architects. Built with **React**, **Vite**, **Tailwind CSS**, **Framer Motion**, and **Lucide React**.

## 🛠️ Stack & Technologies
- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS v3 + CSS Variable Tokens
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Typography**: Plus Jakarta Sans & JetBrains Mono

## 📁 Architecture
```
src/
├── assets/         # Structured assets (profile, projects, certificates, etc.)
├── components/     # Scalable modular section components
├── data/           # Centralized portfolio data (portfolioData.js)
├── App.jsx         # App shell & layout wrapper
├── main.jsx        # Entry point
└── index.css       # Global design system tokens & glassmorphism utilities
```

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
